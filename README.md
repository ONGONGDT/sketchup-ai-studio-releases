# 360i SketchUp AI Studio releases

Official release repository for 360i SketchUp AI Studio, the AI rendering extension for SketchUp 2026 and 2027.

Each release is tagged `v<version>` and carries:

- `360i_ai_studio_<version>_<date>_<commit>_unsigned.rbz`, the extension package (signed packages replace it once Extension Warehouse signing is set up);
- its SHA-256 checksum in the release notes.

The latest release is the current version. Install it from SketchUp's Extension Manager (Install Extension, then pick the `.rbz`). From 1.22.0 on, the extension can update itself: it offers "Update now" when a newer version is out, downloads the package from this repository, checks its SHA-256 and installs it after you click.

Source code is private. Report problems to the 360i team.
